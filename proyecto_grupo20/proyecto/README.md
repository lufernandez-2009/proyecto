## Dependencias e instalación

Para ejecutar el proyecto se necesita:

| Dependencia | Versión | Para qué se usa |
|---|---|---|
| Python | 3.x | Lenguaje del proyecto |
| KivyMD | (anotar la versión instalada) | Interfaz gráfica |

Instalación:

```bash
pip install kivymd
```

## Cómo levantar el proyecto

1. Descargar o copiar la carpeta del proyecto.
2. Instalar las dependencias (ver sección anterior).
3. Abrir una terminal dentro de **carpeta/archivo** del proyecto.
4. Ejecutar:

```bash
python main.py
```
